# 实验反馈与画布提示验收

本次仅增加电流表实验顶部的反馈入口、反馈弹窗，并将画布操作提示移动到左下角。提交为预留功能的本地演示，不发送网络请求，不持久化反馈数据。

## 实现

- 反馈入口位于左上工具栏右侧，沿用相同图标、文字、按钮和背景样式。
- 弹窗包含可编辑的实验名称、反馈描述、截图和提交按钮。实验名称取页面当前显示的标题，即使标题本机保存失败也能准确带入。反馈内修改名称不会修改页面标题。
- 反馈描述引导文字为 12px；截图支持上传本地图片或直接粘贴，显示图片预览。
- 演示提交提示“提交成功（演示，未上传）”并关闭弹窗；关闭按钮与 Esc 均可关闭，恢复反馈入口的键盘焦点。
- 画布操作提示距左侧和底部各 16px。

## 新鲜验证

- 新增 4 项交互测试，先验证原代码因缺少反馈入口而失败。最终全量测试 60 个文件、791 项通过。
- 修改的 4 个 TypeScript 文件 ESLint 通过；`git diff --check` 通过。
- 课程完整性检查、TypeScript 和 Vite 生产构建通过。最终 Vite 构建耗时 27 秒，仍有项目已有的大分块警告。
- 浏览器实际操作：打开弹窗，修改反馈名称、填写描述，通过文件选择器上传图片，预览图片宽度为 1079px。
- 浏览器实际图片粘贴：粘贴用户本次标注图片，预览替换为 1920×870；描述文字不变。测试后恢复空剪贴板。
- 浏览器实际点击提交：成功提示出现且弹窗消失；实验仍为 6 根导线、电表读数 0.2887391722810495A，页面标题没有被反馈名称修改。
- 浏览器实际 Esc 和关闭按钮：关闭后焦点返回反馈入口。
- 浏览器计算样式：描述引导文字为 12px，画布提示左侧和底部间距均为 16px。
