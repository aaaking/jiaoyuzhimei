# 电池组操作验收

验收时间：2026-10-03。页面：http://127.0.0.1:5190/physics/labs/ammeter-use。

## 本次实现

- 点击 E1 本体选中，右侧显示切换方向、设置、删除三个图标。
- 翻转交换电池正负极，保持导线端点及开关机械状态，电流与动态箭头反向。
- 名称、内阻、1.5/3/4.5/6V 电压、旋转角度可修改；作为默认保存到本机，使用初始值恢复 E1、3V、0.2Ω、0°、原方向。
- 内阻选项：0、0.1、0.2、0.5、1、2Ω。0Ω 使用理想电压源约束，短路电流由已有导线电阻决定。
- 旋转使用同一角度计算器材、接线热区和导线端点。
- 删除仅移除电池组和供电，不删导线、不打开机械开关；导线成为可继续重接的悬空端。
- 设置及删除状态进入实验快照，旧快照采用原实验设置；修改设置不会修复已经损坏的电池。
