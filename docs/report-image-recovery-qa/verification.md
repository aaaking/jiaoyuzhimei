# 报告电路图加载修复

## 当前证据与边界

用户截图中的图片元素存在，但图片没有显示。检查时，原始 PNG 文件完整，210×155，3698 字节；本机预览服务器对静态图片返回 HTTP 200 和 `image/png`。两个已有预览页内的已保存报告使用此前上传的内嵌图片，实际均能加载。因此本次未复现用户截图发生时的具体触发条件，不能将“旧地址失效”当作已确认的原始原因。

代码中确认的薄弱点：默认电路图依赖独立静态文件地址；保存报告后直接恢复原始图片地址，默认图引用没有随当前应用资源更新。部署前缀改变或已保存的默认图引用失效时，加载报告不会恢复默认图。

## 修改

- 通过 Vite 的 `?inline` 引入现有 PNG，将默认电路图内嵌到应用资源中，消除独立图片请求和部署前缀依赖。
- 读取已保存报告时，仅将 ID 为 `circuit` 的默认图片引用更新为当前资源。保留报告标题、章节、文字、图片说明和用户上传的其他图片。
- 保留用户主动删除默认图片的结果，不自动重新插入图片。
