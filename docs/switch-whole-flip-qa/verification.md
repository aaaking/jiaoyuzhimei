# 闸刀开关整体翻转修复验收

日期：2026-10-03。页面：http://127.0.0.1:5190/physics/labs/ammeter-use。

## 根因与恢复的不变量

- 原始故障已在浏览器复现：S2 点击方向切换后，黑色端子仍在 x304.5，红色端子仍在 x430.5；两根导线路径完全不变。
- 器材渲染先镜像图片，又用裁剪覆盖原方向接线帽，刻意保持左黑右红。布局只读取旋转角度，不读取 reversed，导线端点和接线热区因此没有一起镜像。
- 原测试检查方向状态字段、开关独立性及电流，不验证翻转后的端子位置和导线几何，未能发现此行为与整体翻转目标不符。
- 修复恢复同一不变量：端子身份绑定在器材上，整体镜像时图片、可交互端子与所有已接导线的端点共用相同几何变换。先镜像局部横向偏移，再应用旋转角度。
- 删去接线帽覆盖层，将两只开关的翻转状态传入布局与拖动处理，电路图符号采用相同镜像。连接的逻辑端点不交换、不新增或删除导线，机械开关状态与电流不变。
