# 电流表选中操作、3D与设置

目标：按用户四张参考图，在既有实验中实现电表选中工具、可旋转分解实体模型、真实设置和电流时间图。保留拖动与导线热区优先级，不改其他实验。

1. 模型任务：独立Three.js组件/几何及测试；真实壳体、玻璃、表盘、端子和内部机构；旋转、分解、重置、资源清理。→ 验证：结构测试与浏览器实际旋转/分解截图。
2. 物理任务：配置验证、内阻参与计算、删除端子及导线、过载、快照和默认设置。→ 验证：控制器回归、异常及持久恢复测试。
3. 集成任务：选中工具条/设置面板/电流图，名称精度与显示同步，删除隐藏器材。→ 验证：真实DOM操作和浏览器实测。
4. 完整验收：全量测试、TypeScript/生产构建、只读审查、视觉合并对比。

接口：MeterSettings={namePrefix,nameNumber,overloadDamage,showGraph,smallResistance,decimals}。三个任务使用独立文件，共享接口由本文件锁定，无共享编辑冲突。UI依赖物理接口；模型按onClose属性独立挂载。

临时决定：图像为I-t电流时间图，不假造交流频率；图示按钮“使用初始值”默认解释为恢复初始配置，“作为默认”本机保存供下一次实验使用，文字差异已通过异步问题请求用户澄清。遵循既有预览与未提交改动，原地施工，不创建提交或发布。
