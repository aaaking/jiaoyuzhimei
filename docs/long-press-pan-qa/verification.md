# 空白画布长按左键平移

## 行为

- 鼠标左键在空白画布按住 300ms 后进入平移，使用已有 `panBy` 相机更新逻辑；鼠标显示抓取状态。
- 等待期间记录最新指针位置，激活时不跳动。松开、取消、失焦或卸载画布均清理等待状态与指针捕获。
- 器材、接线柱、导线命中区、拆下的灯泡及交互控件不启动长按平移。原有空格、中键、右键与双指手势继续可用。
- 底部操作提示增加“空白处长按左键拖动”。
