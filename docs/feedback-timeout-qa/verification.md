# 底部操作提示自动隐藏

2026-10-04。已完成开发、页面复测及独立审查。

电流表实验的底部操作提示显示 5000ms 后隐藏。新反馈对象重新计时；同对象重渲染不续时。反馈变化或卸载时清理旧计时器；仅隐藏显示，不清除实验反馈及会话记录。

审查发现初版共享计时可能改变比热容实验每 250ms 产生新反馈时的显示行为。已令 `autoDismissFeedback` 默认关闭，仅 `PhysicsLabShell` 的 `ammeter-use` 启用；其他实验保持原有行为。`presentation: scene` 不建立计时器，场景故障告警保持原有显示。

## 新鲜验证

- 原生拖线从 3A 端子移至 0.6A，出现“已调整导线连接”，见 `visible.png`；等待 5.5 秒后 `role=status` 为空，见 `expired.png`。拖回 3A 后提示重新出现；原连接已恢复。
- 定时测试覆盖 4999/5000ms 边界、新操作续时、同对象重渲染不续时、scene/null/卸载清理及关闭时其他实验保持显示；独立复跑 4/4 通过。
- 最终完整测试 62 文件、799 项通过，包含真实电流表烧坏/重置告警回归。正常及子路径构建通过。
- 本次未再次在原生页面制造烧坏器材，持续故障告警由代码隔离及自动化回归核验。

独立审查结论：范围隔离后无有证据的 P1/P2 阻塞问题。
