# 去除开合闸底部提示

本次取消 S1、S2 正常打开或闭合时的底部操作提示。开关动作的接受结果、会话状态保存和物理计算仍然执行，现象通过开关外观、电流表读数、灯泡亮度和导线电流动画呈现。

根因：`practiceController` 为开合闸生成的操作反馈默认由 `ImmersiveLabStage` 显示为底部提示。修改仅将开合闸反馈标记为场景已呈现；没有删除反馈或改变电路状态，因此不会切断 `PhysicsLabShell` 依赖接受反馈执行的会话同步。异常现象仍由场景的红色提示展示。
