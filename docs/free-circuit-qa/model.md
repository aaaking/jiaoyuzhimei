# 自由接线电流表实验模型（2026-10-03）

本版取消教学接法对操作的拦截。通断、反接读数、支路电流、灯泡亮度和器材损坏由当前电路计算决定。它是便于课堂观察的简化直流模型，不是特定仪表或电池的实物标定模型。

## 电路计算

使用节点电压法求解每个支路的电流。电源使用带内阻的诺顿等效模型，短路电流保持有限；每根导线的动画采用该导线的电流符号，不再用电流表读数代替全电路电流。

| 器材 | 仿真参数 |
| --- | --- |
| 电池组 | 电动势 3V，内阻 0.2Ω |
| 每根导线 | 0.02Ω |
| 闭合开关 | 0.01Ω |
| 灯泡 | 10Ω；亮度近似按相对于 3V 下电功率的比例显示 |
| 电表大量程输入 | 0.1Ω |
| 小量程输入 | 使用已有设置；0Ω 按 0.001Ω 近似，避免奇异方程 |
| 两量程同时接线 | 保留两条输入支路，按各支路满偏比合成指针偏转；是输入支路近似，不是实物表头/分流器拆解模型 |

电表读数保留正负号。反接时指针可向零位左侧偏转，受可见机械行程限制。灯泡和电流动画独立于电表：没有电表、被旁路或表内损坏时，只要其他支路导通就仍可有电流。浮空部分不产生虚假电流。

## 操作与损坏

- 连接、重接、拆线、闭合开关和带电换量程均允许；不自动扳动任何开关。
- 拉离已有导线端点时，预览中的电路按该导线断开计算；取消拖动相当于放回原接线柱。提交落点时原子替换实际连接。
- 保留端点存在性、非法数据等软件输入校验。图上每对接线柱表示一条导线连接；重复连接接受为同一条连接，避免重复图元，并不以教学接法拒绝操作。
- 电表满偏比绝对值超过 1，开启“过载瞬间损坏”时立即损坏；关闭时允许观察，持续过载 1500ms 后热损坏。反向过载同样处理。损坏模型为表内支路熔断，不改变外部导线与开关位置。
- 电池电流超过 6A，连续维持 3000ms 后损坏并停止供电。解除过流取消本次延迟损坏；这些时间和阈值是课堂仿真参数，不是实测熔断时间或电池额定值。
- 损坏状态写入实验快照；清空接线不会修复器材，完整“重置实验”恢复新器材。撤销/重做作为软件实验编辑能力保留。
- 本版未模拟导线绝缘熔化、触点电弧、燃烧、灯丝热惯性、电池化学状态或连续温度/能量积累。固定 3V 电源与 10Ω 灯泡不会产生超额定电压的灯丝烧毁条件。

原理参考：[OpenStax 电源内阻与端电压](https://openstax.org/books/college-physics-2e/pages/21-2-electromotive-force-terminal-voltage)、[基尔霍夫定律](https://openstax.org/books/university-physics-volume-2/pages/10-3-kirchhoffs-rules)、[电流表与分流器](https://openstax.org/books/college-physics-2e/pages/21-4-dc-voltmeters-and-ammeters)。以上仿真参数由本项目选定，参考资料不为参数或损坏时序提供实物标定依据。

## 当前验证

- 新增自由实验回归初次运行 8 项失败、1 项通过；拖动中途断路回归初次失败；灯泡功率回归初次 2 项失败；持续电表过载的新增路径初次 2 项失败，修复后通过。
- 最终完整测试：54 个文件、712 项通过（/tmp/free-world-final-verification.log）。
- 最终生产构建：课程完整性、TypeScript 与 Vite 通过，13.69s（/tmp/free-world-final-build.log）。修改文件 ESLint 退出 0（/tmp/free-world-final-lint.log）。
- 数值验证覆盖串联欧姆定律、并联支路电流守恒、悬空支路、正反向过载、损坏后的独立并联支路、快照恢复和两量程同时接线。
- 1500ms/3000ms 延迟及及时断线取消的时序均用 fake timers 测试。电池自然计时损坏另已在浏览器实测；关闭瞬间损坏后的电表自然计时未单独做浏览器录像。
- 浏览器原生鼠标复现用户截图：两个开关断开，补上 L1 右柱至 S2 右柱的最后一根线后立即显示 0.289017A（界面 0.29A）、灯泡发光和 56 个动画箭头；删除此线后 0A、无动画，重接恢复供电。
- 浏览器实测反接：-0.289017A，指针 rotate(-63.21194605009745)，灯泡仍亮和 56 个方向箭头。
- 浏览器实测 S2 闭合：接受操作，五根导线保留，S1 仍断开、S2 闭合，7.69A 过载导致表内损坏和读数归零。
- 浏览器实测电池直接短接：13.64A、8 个箭头，之后电池损坏、箭头归零，短接导线保留。
- 最终版本浏览器实测带电切换 0.6A/3A：电流分别 0.291800A/0.289017A，两只开关位置保持断开；预览最终保留用户截图接法的 3A 通电状态，可继续操作。
