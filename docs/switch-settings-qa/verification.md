# 闸刀开关独立操作验证（2026-10-03）

## 实现范围

S1、S2 各自保存名称、机构方向、断路状态、旋转角度和删除状态。选中底座显示切换方向、设置、删除；点击闸刀或握柄仍只开合开关。方向切换保持左黑右红接线帽；旋转同时更新图像、把手命中区域、接线柱热区及导线端点。

按用户截图将“短路设置”解释为“断路设置”：按钮启用后显示红色断路标记，求解器移除该开关内部导通支路，即使闸刀机械闭合也不导通。

删除开关保留全部导线及其几何位置，去除开关本体和接线柱热区；原线端以悬空导线端显示，可以继续拖动重接。保存快照包含各开关设置与删除状态，旧快照恢复为默认设置。

## 新鲜证据

- 开发前新增测试复现了缺失的独立设置、操作入口、旋转端点和反向把手命中（11 项失败）。实现后针对测试通过。
- 最终全量测试：55 文件、724 项通过。修改文件 ESLint 无错误，完整生产构建通过（内容完整性检查、TypeScript、Vite；15.74 秒），`git diff --check` 通过。
- 原生浏览器点击 S2 反向把手：合上、拉开都成功；设置角度 90° 后，反向把手仍可合上、拉开。
- S2 更名为 K2、设置断路并闭合后，S1 正常供电，电流 0.288739 A、灯泡发光。S1 名称和设置不受 S2 编辑影响。
- 删除已旋转的 S2：DOM 核验六根导线的标识和路径前后完全一致，留下两个悬空端，S1 继续供电。
- S1 闭合时启用断路，读数即时归零、灯灭；解除断路恢复 0.288739 A。删除 S1 后读数归零，两只开关共留下四个悬空线端，六根导线路径前后完全一致。
- 原生拖动 S2 遗留的悬空线端到电流表 0.6A 接线柱，重接成功，导线仍为六根，悬空端由四个减为三个。
